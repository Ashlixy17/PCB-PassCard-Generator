# PCB-PassCard-Generator
### 界面预览
![通行证模板设计界面](assets/PCB-PassCard-Generator-preview.png)

## 功能

- 查询和选择内置角色，或切换到自定义录入编辑通行证信息。
- 调整姓名、编号、职业和阵营，上传照片、透明抠图或自定义图标。
- 查看 PCB 正反面效果，直接选择预设阻焊颜色或自定义颜色；浅色阻焊自动搭配深色丝印预览。
- 使用滑动选中块切换“纯灰度三分分层”与“彩色识别分层”，两种工艺分别保存全局与独立素材参数，旧参数自动迁移到灰度模式。
- 灰度模式沿用明暗阈值三分；彩色模式按 HSV 识别金属颜色，支持沉金、喷锡与 OSP，分别查看金属、阻焊下覆铜、裸基材及制造层。可按相似颜色或灰度区间识别裸基材。
- 进入“详细调整”设置丝印阈值、阻焊开窗阈值、边缘加粗和抗锯齿平滑，查看丝印、铜、阻焊开窗图层。
- 按独立素材设置材料、明暗、内部细节和显隐；阵营 Logo 保留原始纹理，可以单独调整位置与缩放。
- 在后台处理分色和绘图，按素材缓存计算结果；正反面切换直接使用缓存，拖动时快速预览，松手后恢复完整精度。
- 下载 PCB 效果 PNG，或导出正反面的丝印、铜、阻焊开窗、板形蒙版和处理参数 ZIP；图纸尺寸为 590 × 1180 px。

分层 PNG 中，黑色表示该层有效图形，透明表示无图形；阻焊层的有效图形表示**开窗**。沉金区域由铜与开窗共同形成。当前导出是分层图片，实际尺寸、线宽与间距需要在 PCB 工具中核对后生成 Gerber。

彩色模式的 ZIP 额外包含 `F/B.ENIG.png`（或 `HASL`、`OSP`）、`CoveredCu`、`Substrate` 材料区域图，供检查和导入参考；制造分层仍使用 `Cu`、`Mask`、`SilkS`。主预览与详细调整中的图层列表随当前工艺变化，重置只影响当前工艺。分层模式及彩色识别思路参考 [PCB_lightgraph Portable](https://ashlixy17.github.io/PCB_lightgraph_Portable/)，在本项目的独立素材与后台处理管线中实现。

## 开发说明

- [当前预览的组成与 PCB 分层改造入口](docs/preview-composition.md)：已核对的独立素材、动态绘制内容、覆盖顺序与局部处理接入位置。
- 分层与绘图运行在 `src/workers/pcb.worker.ts`，调度器只保留一个最新预览任务，显式导出独立排队并使用完整精度。支持 OffscreenCanvas 的浏览器直接接收 ImageBitmap；其他支持 Worker 的浏览器接收后台生成的像素数据。
- 启动开发服务后可打开 `/tests/pcb-worker-smoke.html`，检查繁重处理期间的界面响应、连续请求合并和 PNG 与原算法的逐像素一致性。该测试页面不进入正式构建。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，推荐使用 Chrome 或 Edge。

```powershell
npm ci
npm run dev
```

开发页面：`http://127.0.0.1:3000/PCB-PassCard-Generator.html`。

## 构建与部署

```powershell
npm run lint
npm run test:pcb
npm run build
npm run preview
```

构建产物在 `dist/`，入口为 `PCB-PassCard-Generator.html`。部署时一起发布整个 `dist/`，通过站点下的 `/PCB-PassCard-Generator.html` 访问应用；入口 HTML 和旁边的 `PCB-PassCard-Generator_assets/` 必须保留相对目录关系。

构建只写入本仓库的 `dist/`，不再向 PCB 编辑器仓库复制文件。源码入口需要通过 Vite 启动；浏览器直接双击源码 HTML 无法运行 React／TypeScript。

角色库、裁剪偏好和 PCB 分色参数保存在当前浏览器的本地存储中；新站点不会自动读取旧站点的本地存储。上传的图片需重新选择。旧亚克力渲染、3D、GIF 和 AR 源码保留作为迁移参考，当前界面使用 PCB 预览与导出。
